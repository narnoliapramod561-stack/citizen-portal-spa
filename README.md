# Stitch MCP Configuration

This project is configured to use **Stitch**, a powerful UI generation and design system service from Google.

## Configuration Details

The workspace contains a `stitch_config.json` file which includes the following:
- **Server URL**: `https://stitch.googleapis.com/mcp`
- **MCP Server Name**: `stitch`

## How to Use

If you are using an AI assistant or an MCP client (such as Cursor, Windsurf, or Claude Desktop), you can point it to this configuration or use the tools provided by the `StitchMCP` server.

### Available Tools

Through Stitch, you can:
- **Generate Screens**: Quickly prototype UI from text prompts.
- **Edit Screens**: Modify existing designs.
- **Manage Design Systems**: Create and apply consistent styling tokens (colors, typography, etc.).
- **Manage Projects**: Organize your UI assets into projects.
